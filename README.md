# @lp-labs/bulk-design

Bounded, validated record-to-design-slot binding and sequential asynchronous exports through your adapter. Independent **0.1.0** MIT package; zero runtime/peer dependencies; Node 18+, ESM/CJS with strict TypeScript declarations.

## Install and quickstart

```sh
npm install @lp-labs/bulk-design
```

```js
import assert from 'node:assert/strict';
import { bindRecords, runBulkDesign } from '@lp-labs/bulk-design';

const template = {
  slots: [
    { id: 'title', kind: 'text', required: true },
    { id: 'copies', kind: 'number', default: 1 },
  ],
};
const records = [
  { id: 'alice', values: { name: 'Alice' } },
  { id: 'bob', values: { name: 'Bob' } },
];
const bindings = [{ column: 'name', slot: 'title' }];
assert.deepEqual(bindRecords(template, records, bindings)[0].slots, { title: 'Alice', copies: 1 });
const result = await runBulkDesign(template, records, bindings, async (design) => ({
  fileName: `${design.recordId}.txt`,
  mediaType: 'text/plain',
  data: new TextEncoder().encode(`Hello ${design.slots.title}`),
}));
assert.equal(result.status, 'completed');
assert.equal(result.attempted, 2);
assert.equal(new TextDecoder().decode(result.successes[1].output.data), 'Hello Bob');
```

This example exports actual UTF-8 text. For rendered designs, supply your real SVG/raster/document renderer in the adapter; no PNG/PDF encoder or cloud export is simulated.

## API and types

Runtime exports: **`bindRecords`**, **`runBulkDesign`**, **`BulkDesignError`**. CJS: `const { runBulkDesign } = require('@lp-labs/bulk-design')`.

| Exported type  | Fields/contract                                                                   |
| -------------- | --------------------------------------------------------------------------------- |
| `SlotValue`    | String, finite number or boolean. No null, objects or undefined.                  |
| `DesignSlot`   | `id`, `kind: 'text'                                                               | 'number' | 'boolean'`, optional boolean `required`, optional typed `default`. |
| `BulkTemplate` | Nonempty ordered `slots` array.                                                   |
| `BulkRecord`   | Unique `id` and plain `values: Record<string,SlotValue>`.                         |
| `SlotBinding`  | `{column,slot}`; unique source column and unique target slot.                     |
| `BoundDesign`  | `{recordId,slots}` with immutable detached typed slot values.                     |
| `BulkOutput`   | `{fileName,mediaType,data:Uint8Array}`; real adapter-generated bytes.             |
| `BulkExporter` | `(design,index,signal?) => Promise<BulkOutput>`.                                  |
| `BulkLimits`   | `maxRecords`, `maxSlots`, `maxStringLength`.                                      |
| `BulkOptions`  | Limits plus `maxOutputBytes`, `continueOnError`, `signal`.                        |
| `BulkSuccess`  | `{index,recordId,output}`.                                                        |
| `BulkFailure`  | `{index,recordId,error:unknown}`; exact thrown reason or output-validation error. |
| `BulkResult`   | `{status:'completed'                                                              | 'failed' | 'cancelled',successes,failures,attempted,total}`.                  |

- `bindRecords(template, records, bindings, options?): readonly BoundDesign[]`: validates **all** input, producing a deeply frozen plan in record order.
- `runBulkDesign(template, records, bindings, exporter, options?): Promise<BulkResult>`: binds the entire plan before any export, then awaits one adapter at a time. Each adapter receives its immutable design, zero-based input index and optional signal.

Text slots require strings; numeric slots require finite numbers; boolean slots require booleans. No coercion or placeholder expansion occurs. Absent bound columns use a slot default, then fail if required, otherwise omit the slot completely (no undefined placeholders). Empty strings, zero and false are real present values. Unbound record columns, unknown slots, repeated bindings/IDs and invalid defaults are rejected.

## Partial failure and cancellation

Validation/configuration failures reject before any export starts. Runtime exporter rejection and invalid outputs are recorded as per-record failures:

- Default `continueOnError: false`: stop immediately at first failure; earlier successes are retained.
- `continueOnError: true`: continue subsequent records; final status is `failed` if any failure occurred.
- `attempted` counts adapter invocations; `total` counts validated input records. Unattempted records have no fabricated success/failure entry. Success/failure indices preserve original input indices, not compact result indices.
- Pre-abort returns `cancelled` with zero attempts **after input validation**. Abort during an in-flight export waits for settlement and returns `cancelled`; that item's output/rejection is omitted, prior completed results are retained and no next export begins.
- Cancellation takes precedence over an in-flight adapter rejection. Status `cancelled` may still contain failures from earlier records.

An exporter ignoring its signal can continue running. Side effects/file writes cannot be rolled back. No retries, timeouts, durable resume, parallel export, cross-run scheduling, automatic cleanup or atomic all-or-nothing batch guarantee exists. Separate runs can overlap; each individual run is sequential.

## Customize

```js
import assert from 'node:assert/strict';
import { runBulkDesign } from '@lp-labs/bulk-design';

const template = { slots: [{ id: 'title', kind: 'text', required: true }] };
const records = [
  { id: 'a', values: { name: 'A' } },
  { id: 'b', values: { name: 'B' } },
  { id: 'c', values: { name: 'C' } },
];
const result = await runBulkDesign(
  template,
  records,
  [{ column: 'name', slot: 'title' }],
  async (design, index) => {
    if (index === 1) throw new Error('renderer unavailable');
    return {
      fileName: `${design.recordId}.txt`,
      mediaType: 'text/plain',
      data: new TextEncoder().encode(design.slots.title),
    };
  },
  { continueOnError: true, maxRecords: 10, maxOutputBytes: 1024 },
);
assert.equal(result.status, 'failed');
assert.deepEqual(
  result.successes.map((item) => item.recordId),
  ['a', 'c'],
);
assert.equal(result.failures[0].index, 1);
assert.equal(result.attempted, 3);
```

Templates describe slots, not geometry. Adapters own rendering, layout, output codecs, licenses and storage. Outputs are validated but not decoded or verified as their declared MIME format. Output records/results/arrays are frozen; byte buffers are detached copies (including Node Buffers) and remain caller-mutable. Failure reasons retain their original identity and are not JSON-serialized.

## Errors and limits

`BulkDesignError(code, message)` extends `Error`:

| `code`     | Meaning                                                                             |
| ---------- | ----------------------------------------------------------------------------------- |
| `invalid`  | Invalid input/options/bindings/types or missing required data.                      |
| `capacity` | Input record/slot/column/string limit, or per-output byte limit.                    |
| `output`   | Malformed/empty bytes, unsafe filename, or invalid media type returned by exporter. |

| Setting           |   Default |       Allowed |
| ----------------- | --------: | ------------: |
| `maxRecords`      |       100 |       1..1000 |
| `maxSlots`        |       100 |       1..1000 |
| `maxStringLength` |      4096 |     1..65,536 |
| `maxOutputBytes`  | 1,048,576 | 1..16,777,216 |

`maxSlots` independently bounds template slots, bindings and columns per record. Empty record lists are valid. IDs/slot/column names: non-whitespace strings up to 128 UTF-16 units without controls. Values/default strings count UTF-16 units. Names and MIME values are at most 128 units: filenames allow a safe ASCII basename starting alphanumeric with letters/digits/underscore/hyphen/dot thereafter, no `..`; MIME values must be lowercase without parameters. No path is opened by this library.

Plain record descriptors are validated without invoking getters; symbols, nonenumerable/accessor properties, custom prototypes and invalid scalar values are rejected. Prototype-sensitive keys remain data. Buffering bounds are per record/output; aggregate memory scales with `maxRecords × maxSlots × maxStringLength` and retained successful output bytes. Reduce limits or process separate batches for large workloads; there is no streaming output sink.
